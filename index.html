Core Course Topics for Each Engineering Wing

Interactive syllabus breakdown structured across foundational engineering principles, algorithmic mastery, enterprise systems, and next-generation artificial intelligence.

BCS502 Sem V • 4 Credits

Web Technologies & Cloud Applications

Foundations of client-server paradigms, HTML5 semantic structure, modern CSS Grid/Flexbox layouts, asynchronous DOM processing, HTTP/2, REST architectural style, and cloud deployment pipelines.

Unit 1: Web Architecture, HTTP protocol & Semantic HTML5
Unit 2: Modern CSS3 Grid, Flexbox, Responsive Media Queries
Unit 3: JavaScript ES6+, Asynchronous Fetch, DOM APIs
Unit 4: Server-side Node.js, Express & JSON Web Tokens
Unit 5: RESTful Web Services, XML/JSON parsers, Security
CSE IT Core Paired Lab: BCS552 →
BCS301 Sem III • 4 Credits

Data Structures & Algorithm Design

Rigorous analytical foundations for complexity analysis (Big-O, Omega, Theta), non-linear hierarchies (AVL, Red-Black trees, Heaps, B-Trees), graph algorithms, divide & conquer, and dynamic programming.

Unit 1: Asymptotic Analysis, Array representations & Stacks
Unit 2: Queues, Linked Lists & Circular Structures
Unit 3: Binary Trees, AVL, Heaps & Priority Queues
Unit 4: Graph Traversals (BFS/DFS), Dijkstra & MST
Unit 5: Sorting Analysis, Hashing & Collision resolution
CSE Core IT Core AI-ML Core
BCS501 Sem V • 4 Credits

Machine Learning & Neural Architectures

Mathematical paradigms of pattern recognition, gradient descent optimization, cost functions, SVMs, decision trees, ensemble bagging/boosting, and artificial neural networks with backpropagation.

Unit 1: Introduction to Statistical Learning & Loss Functions
Unit 2: Linear/Logistic Regression, Regularization (L1/L2)
Unit 3: Support Vector Machines, Kernels & Decision Trees
Unit 4: Unsupervised K-Means, PCA & Dimensionality Reduction
Unit 5: Multi-Layer Perceptrons & Backpropagation Math
AI-ML Major CSE Elective
BCS401 Sem IV • 4 Credits

Operating Systems & Systems Programming

Deep dive into concurrency, process synchronization (Semaphores, Mutexes, Monitors), CPU scheduling heuristics, deadlocks handling, virtual memory paging/segmentation, and file system management.

Unit 1: Kernel Architecture, System Calls & Process States
Unit 2: Threading, Multiprogramming & CPU Scheduling
Unit 3: Process Synchronization & Deadlock Prevention
Unit 4: Memory Hierarchy, Paging & Page Replacement
Unit 5: Disk Scheduling (SCAN/C-SCAN) & UNIX Protection
CSE Core IT Core
BAI601 Sem VI • 4 Credits

Deep Learning, Vision & NLP

Advanced architectures including Convolutional Neural Networks (CNNs), Recurrent Neural Networks (RNNs, LSTMs), Attention Mechanisms, Transformer models, and Computer Vision edge-detection filters.

Unit 1: Deep Feedforward Nets & Vanishing Gradient Mitigations
Unit 2: CNN Filters, Pooling, ResNet & Transfer Learning
Unit 3: Sequence Modeling: RNN, GRU & LSTM Architectures
Unit 4: Attention Mechanism & Transformer Multi-Head Math
Unit 5: Large Language Models (LLM) fine-tuning & NLP tasks
CSE-AIML Core
BCS403 Sem IV • 4 Credits

Database Management Systems

Relational data models, Entity-Relationship modeling, relational algebra, SQL DDL/DML, normalization (BCNF, 4NF), ACID transactions, concurrency serializability, two-phase locking, and crash recovery.

Unit 1: ER Diagrams, Three-Schema Architecture & Relational Algebra
Unit 2: SQL Complex Subqueries, Joins, Views & Indexing
Unit 3: Functional Dependencies, Normal Forms (1NF to BCNF)
Unit 4: Transaction Processing, ACID Rules, Conflict Serializability
Unit 5: Lock-based Protocols, Timestamps, WAL & Recovery
